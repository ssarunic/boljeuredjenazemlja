# CLI reference has moved

The command-line documentation is now maintained per command, in two
languages, and generated from the CLI itself:

- English: [docs/en/cli/start-here.md](en/cli/start-here.md) (tutorial) and
  [docs/en/cli/reference.md](en/cli/reference.md) (every command)
- Hrvatski: [docs/hr/cli/start-here.md](hr/cli/start-here.md) (vodič) i
  [docs/hr/cli/reference.md](hr/cli/reference.md) (sve naredbe)

How the pages are written and kept in step with the code is described in
[specs/documentation-guide.md](../specs/documentation-guide.md).
